**SymDALI** is a Mathematica implementation of [DALI](https://arxiv.org/abs/1401.6892) with symbolic differentiation. It is actively being developed for applications in [gravitational waves](https://arxiv.org/abs/2203.02670).

An example application is show in this [Figure](https://github.com/Felipe-4/SymDALI/tree/main/Demo/Overplot.pdf). It is the exact likelihood (black), Fisher approximation (blue), DALI order 2 (red) and DALI order 3 (green). The event has SNR of 109. The assumed network was 2 ET L-shaped and 1 CE detectors. The waveform is ```IMRPhenomD``` and it includes the extra parameters from the [```TIGER```](https://arxiv.org/pdf/1311.0420) framework, from inspiral to ringdown. This examples uses the parameter \delta_1.

The DALI order 2 result takes around ~ 15 minutes (using [```emcee```](https://arxiv.org/pdf/1202.3665)) to run, while the exact likelihood takes around 13 hours (using [```nessai```](https://arxiv.org/pdf/2102.11056)). We have released an arXiv manuscript on the use of DALI for TIGER parameters with ```IMRPhenomD```, see [2609.38399](https://arxiv.org/abs/2609.38399), we discuss the approximation quality and performance gains in detail. 

At the moment this repository supports the calculation of DALI tensors to order 4 for ```IMRPhenomD``` and ```IMRPhenomHM```. The file ```UserGuide.wl``` in [Demo](https://github.com/Felipe-4/SymDALI/tree/main/Demo) has some examples on how to use part of the functionality of the code. Right now it is fully functional on MacOs Apple Silicon M1. I am currently testing the Windows and Linux functionality. A "Read the Docs" page is also under development.
